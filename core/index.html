Invariant core

A working vocabulary for what persists when a structure passes between code, image, voice, object, record, and proposition.

Working statement

An invariant is not a fixed appearance. It is a selected relation that remains legible through transformation. This archive tests which relations survive a change of material, scale, procedure, or description.

Transformations

  • Code becomes image.
  • Image becomes synthetic object or JPEG corpus.
  • Gesture becomes a situated digitised trace.
  • Instruction becomes syntax and voice.
  • Physical record becomes a photographed proposition.
The question is not whether each form is identical. The question is which relation remains when identity is no longer available.
