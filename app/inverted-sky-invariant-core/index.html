?inverted-sky-invariant-core

A geo-positioned touch framework in which gate logic is applied while touch input is digitised.

Framework page · application interface forthcoming

Operational sequence

Touch becomes a timed sample stream. The system can relate the sample to orientation, local position, and a chosen inverted-sky frame, then evaluate it through a gate before rendering or recording a trace.

gesture → digitisation → local frame → gate evaluation → rendered record

Privacy position

The future application will request location or orientation only after an explicit user action. Its initial design is local-first: no touch, location, or orientation data is uploaded automatically.

Current state

This landing page reserves the public address for the running framework. The executable instrument and its methods will appear here as the system is published.
