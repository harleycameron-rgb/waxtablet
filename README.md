# WAX TABLET

Source for [waxtablet.co.uk](https://waxtablet.co.uk), an archive of invariant media systems.

## Publish with GitHub Pages

In this repository, go to **Settings → Pages**, select **Deploy from a branch**, then select the `main` branch and `/ (root)` folder.

The `CNAME` file is already set to `waxtablet.co.uk`. The domain's DNS must be pointed to GitHub Pages through GoDaddy before the custom domain will resolve.
